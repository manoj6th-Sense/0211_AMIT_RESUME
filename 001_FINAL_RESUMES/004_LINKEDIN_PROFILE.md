## ABOUT (LinkedIn limit 2,600 characters)

I build the infrastructure that makes AI agents dependable in real work, and I deploy it the way a forward-deployed engineer does: inside your workflow, against your failures.

For 15 years at Moody's Analytics and in bank risk consulting I built data platforms and proved that credit-risk models were implemented exactly as specified. Since 2025 I have applied that discipline full time to LLM-agent systems, shipping 20+ tools and platforms.

What I own end to end:

→ Claude Code Center, a self-hosted LLM gateway that routes the Claude Code agent to Google Vertex AI (Gemini, Claude, and third-party models such as Kimi K2 and DeepSeek), AWS Bedrock, OpenRouter, OpenAI or local Ollama, with tool calling on non-Anthropic models, prompt caching, a per-request cost HUD and no subscription lock-in.

→ AMTrix Plan, a drop-in governance standard for AI coding agents: all seven Claude Code hook events, pre-edit backups, approval in the human's own words, a pre-commit secret gate, and "done" measured by tests the code runs, never typed by the model. About 23K lines of stdlib Python with 700+ automated tests.

→ A private AI node on a 64 GB Apple Silicon Mac: 30B mixture-of-experts models with 256K context via Ollama, Open WebUI, private search and a Tailscale layout.

→ A multi-model MCP server that keeps IDE context small (pass-by-path, drill-down, anti-truncation), and a dependency-free execution harness that hashes every request and refuses to call a partial response complete.

→ Deterministic "compute, then narrate" engines, a vision-LLM automation framework where the model decides and a state machine executes, and a real-time multi-channel alerting platform on my own ntfy infrastructure.

How I work: I get into the details of a complex process, break it into small, lightweight, plug-and-play modules, and rebuild it so it is simple to use. Every failure becomes a rule enforced by code.

Open to Forward Deployed Engineer, AI Solutions Architect and Agent Platform roles, full-time or 1099. New York area or remote.
